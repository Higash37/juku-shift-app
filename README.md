# シフト提出アプリ

塾の講師が **シフト** を提出するためのWebアプリです。

## 機能

- [x] 校舎名選択
- [x] 講師プルダウン
- [x] 複数日カレンダーモーダル
- [x] 授業時間追加

## 技術構成

- `Google Apps Script`
- `HTML / CSS / JavaScript`
- `Google Spreadsheet`

### 参考リンク
[Google Apps Script](https://developers.google.com/apps-script)

## ファイル構成

```
Code.gs    - GAS側の処理
Style.html - CSSスタイル
index.html - 画面のHTML
```
